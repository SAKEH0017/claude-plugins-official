# Shot List 范例

下面 3 个完整范例覆盖典型场景:**流程图 / 对比 / 隐喻**。

---

## 范例 1:流程类(讲"三条管道")

适用文章段落:

> 当一个域名请求进来,系统会按顺序穿过三层管道:边缘缓存、安全网关、业务路由。每层各司其职,缺一不可。

**Shot List 输出**:

```
## Shot 1: 三层管道

- 段落引用: "系统会按顺序穿过三层管道:边缘缓存、安全网关、业务路由"
- 概念名: 三层管道
- 场景描述: 一个小黑站在画面左侧,面前是三条平行流向右侧的细长管道,
  每条管道上有一个对应的方框或齿轮元素;小黑用手指向第一条管道
- 小黑动作: 站立,右臂抬起指向左侧第一条管道
- 中文标签: 边缘缓存 (在管道1上方) | 安全网关 (管道2) | 业务路由 (管道3)
- 风格强调: 16:9 白底 + 黑色细线 + 红色中文标签 + 大量留白
- 元素数量: 3 管道 + 1 小黑 + 3 标签 = 7(略多,可简化为 1 个示意管道+2个虚线)
```

**注意**:这个 Shot 元素超过 5 个,在范例中演示"如何精简"。实际生成时应该:

```
简化场景描述: 一个小黑站在画面中央,面前一条横贯的长管道,
管道上中下分别标注三个标签;小黑双手在管道中段,示意"流过这里"
```

## 范例 2:对比类(讲"v1 vs v2")

适用文章段落:

> 旧版配置需要重启服务才能生效,新版则可以热加载。这一改变让部署效率提升了一个数量级。

**Shot List 输出**:

```
## Shot 1: 冷启动 vs 热加载

- 段落引用: "旧版配置需要重启服务才能生效,新版则可以热加载"
- 概念名: 热加载
- 场景描述: 画面左右分两个场景,左侧小黑站在一台标"旧"的机器旁,
  机器前有红叉;右侧同样的小黑站在标"新"的机器旁,机器前有绿色对勾
- 小黑动作: 左侧低头失落状,右侧昂首双手叉腰
- 中文标签: 旧·重启 (左侧) | 新·热载 (右侧)
- 风格强调: 16:9 白底 + 黑色细线 + 红色中文标签 + 左右二分构图
- 元素数量: 2 机器 + 1 小黑(两次出现,可接受) + 2 标签 = 5
```

**注意**:左右对比构图,要明确告诉 API 这是同一角色的两个姿态变体,不是两个人。

## 范例 3:隐喻类(讲"等待评审")

适用文章段落:

> 提了 PR 之后,大部分时间都在等 reviewer。这一步看似被动,实则是协作的关键节点。

**Shot List 输出**:

```
## Shot 1: 等评审

- 段落引用: "提了 PR 之后,大部分时间都在等 reviewer"
- 概念名: 等待节点
- 场景描述: 小黑坐在画面中央一张极简的椅子上,旁边是一张桌子,
  桌上一杯咖啡;远景是一个对话框气泡,内含一个对勾;整体静态、安静感
- 小黑动作: 端坐椅子,双手放膝盖,目视前方对话框
- 中文标签: 等 (小黑头上一行) | 评审 (对话框内) |
- 风格强调: 16:9 白底 + 黑色细线 + 红色中文标签 + 静态构图
- 元素数量: 1 小黑 + 1 椅子 + 1 桌子 + 1 咖啡 + 1 对话框 + 2 标签 = 7(略多)
```

**精简后**:

```
场景: 小黑坐在画面中央,旁边一个小气泡内画"reviewer 头像轮廓 + ?",
其余大面积留白
小黑动作: 静坐,双手放膝
中文标签: 等 (小黑上方)
```

## Shot List 输出模板(供 LLM 复用)

```
## Shot <N>: <概念名 2-6 字>

- 段落引用: "<原始段落关键句,不超过 30 字>"
- 场景描述: <一句话视觉场景,含小黑姿态 + 关键元素>
- 小黑动作: <小黑的具体动作>
- 中文标签: <标签1>(<位置>) | <标签2>(<位置>) | <最多 4 个>
- 风格强调: 16:9 白底 + 黑色细线 + 红色中文 + 留白 ≥ 60%
- 元素清点: <数字><= 4 视觉实体(不含小黑)>
```

**节俭原则**:如果一个 Shot 的视觉实体超过 4 个,**优先合并或拆成两个 Shot**。一图一概念不可妥协。
