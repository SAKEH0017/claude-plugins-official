# 小黑 IP 角色规格

小黑是 Skill 的视觉锚点 —— 所有插图都必须包含他。规格是为了让不同 API 出图风格保持一致。

## 视觉规格

- **身体**:实心黑色色块(`#120F0F` 或 `#000000`),无轮廓线、无渐变
- **形状**:圆润椭圆或胶囊形,无棱角
- **眼睛**:两个白色圆点(`#FFFFFF`),直径约为身体宽度的 1/8,**不能是整张脸只有眼睛**(嘴唇必须居中)
- **表情**:空白无表情(无嘴、无眉毛、无情绪符号)。"bizarre but clean"
- **腿**:两条黑色火腿状短腿,细,约占身高的 1/4
- **手**:可有可无,若有应极简(火腿状或圆形),与身体同色
- **比例参考**:
  - 身体高度 = 角色在画面中高度的 60-70%(留出动作空间)
  - 角色整体水平居中或遵循三分线
  - 不与中文标签重叠

## 标准姿态库

构图时挑选一个,确保动作与场景语义强相关:

| 姿态 | 适用场景 |
|------|---------|
| 站立注视某物 | "观察/分析" 类认知锚点 |
| 推一扇门 / 推东西 | "突破/进展" 类 |
| 搬/举一个物体 | "代码/DN 配置" 等流程图 |
| 走在一条路上 | "路径/方法论" 类 |
| 站在山顶/原点 | "起点/终点" 类 |
| 陷入或被包裹 | "陷阱/困境" 类(慎用,避免负面情绪过重) |
| 拉线/拽线 | "连接/依赖" 类 |

**自检规则**:把小黑从画面中抹掉,该插图传达的核心概念应变得无法理解。

## 反例(禁止)

- 小黑戴墨镜、戴帽子、穿衣服(会让 IP 失去辨识度)
- 小黑张嘴笑、皱眉、流汗(无表情是核心)
- 小黑变成其他颜色或渐变
- 小黑变成拟人化(西装/手机/电脑) — 这破坏了 "bizarre but clean" 的反差
- 多个小黑同时出现(每个 Shot 只允许一个小黑)
- 小黑用白色边框勾边(无边框是规则)

## Prompt 中如何描述

英文 prompt 模板段(直接复用):

```
IP character "小黑" (Xiaohei): solid black silhouette body in egg/oval form,
two tiny white dot eyes, thin stick legs, blank expression,
wearing nothing, NO hat/glasses/clothes/mouth/eyebrows,
must actively perform the scene's core action.
```

关键否定词:`NO hat`、`NO clothes`、`NO mouth`、`NO expression`、`silhouette`。
